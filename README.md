# Cross-City Generalization of Ensemble Machine Learning Models for Micromobility Demand Prediction with Explainable AI

*Course project on cross-city generalization of ensemble ML models for shared micromobility.*

## Project Overview
Shared micromobility (shared bikes and e-scooters) is vital for modern urban transport. However, most Machine Learning models predicting their demand are trained on a single city, failing to generalize to new environments due to domain shift, and often act as "black boxes."

This research evaluates the cross-city generalization of ensemble models (XGBoost, Random Forest, LightGBM, CatBoost) using data from two different cities. We will train models on one city (New York City) and test them on another (Chicago), using Explainable AI (SHAP) to compare feature importance. Findings will provide actionable insights for fleet operators adapting to new regions.
